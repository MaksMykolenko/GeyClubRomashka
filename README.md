# Сайт гей-клубу «Ромашка» (Romashka Gay Club)

Сучасний, стильний та інклюзивний вебсайт гей-клубу **«Ромашка»**, створений на **Next.js (App Router)**, **TypeScript**, **Tailwind CSS** та **Framer Motion**.

Атмосфера сайту натхненна офіційною афішею закладу: неоново-рожеві, фіолетові та електрично-сині кольори, світящі ромашки, нічні прожектори, дзеркальні кулі та м’який клубний дим.

---

## 🚀 Основні можливості

- **Головна сторінка (`/`)**: Атмосферний hero-блок із використанням постера закладу, інформацією про найближчу вечірку, віковим бейджем `18+` та кнопкою купівлі квитка.
- **Афіша подій (`/events`)**: Інтерактивна сітка подій з фільтрацією за категоріями (*Усі події*, *Вечірки*, *Live*, *Drag*, *Special events*) та пошуком.
- **Сторінка окремої події (`/events/[id]`)**: Повна картка події з розкладом (timetable), лайнапом артистів, правилами входу, ціною та демо-купівлею квитків.
- **Про клуб (`/about`)**: Емоційна розповідь про простір, його цінності (свобода самовираження, взаємна повага, активна згода, нульова толерантність до дискримінації).
- **Галерея (`/gallery`)**: Фільтрована фотогалерея з повноекранним Lightbox переглядом та навігацією клавішами (`Esc`, `←`, `→`).
- **Відвідування (`/visit`)**: Практична інформація, адреса, дрес-код, правила входу, доступність для людей з інвалідністю та інтерактивна карта.
- **Безпека & Safe Space (`/safety`)**: Правила клубу та анонімна форма відправки повідомлень про інциденти без публічного розкриття даних.
- **Бронювання & Guest List**: Форма бронювання столиків і запису в список гостей із перевіркою полів, станом завантаження та honeypot-захистом від спаму.
- **Мультимовність (i18n)**: Повна підтримка Української (`uk`), Польської (`pl`) та Англійської (`en`) мов через словники локалізації.
- **Вікове підтвердження (18+ Age Gate)**: Елегантне модальне вікно при першому вході з фіксацією в `localStorage`.
- **SEO & Accessibility**: Schema.org JSON-LD структуровані дані для `NightClub` та `Event`, `sitemap.xml`, `robots.txt`, адаптація `prefers-reduced-motion` та WCAG AA контрастність.

## 🛠 Інструкція з локального запуску

### 1. Установка залежностей
```bash
npm install
```

### 2. Запуск локального сервера розробки
```bash
npm run dev
```
Сайт буде доступний за адресою: `http://localhost:3000`

### 3. Перевірка типів та лінтинг
```bash
npm run typecheck
npm run lint
```

### 4. Збірка Production бандлу
```bash
npm run build
npm run start
```

## ⚙️ Конфігурація та плейсхолдери для власника

Усі основні параметри клубу винесені в єдиний конфігураційний файл:
📄 `src/config/club.config.ts`

Власнику закладу потрібно замінити такі дані:
- `addressPlaceholder` — реальна адреса закладу (наприклад: *м. Київ, вул. Нічна, 12*)
- `metroStation` — найближча станція метро
- `phone` — номер телефону підтримки
- `email` — email закладу
- `socials` — посилання на офіційні акаунти Instagram, TikTok, Telegram, Facebook
- `NEXT_PUBLIC_TICKET_SERVICE_URL` — у файлі `.env` вкажіть реальний URL сервісу квитків (наприклад, Concert.ua або Karabas).
