# 🌼 Гей-клуб «Ромашка» (Romashka Gay Club)

Сучасний, інклюзивний та мінімалістичний вебсайт гей-клубу «Ромашка», виконаний у стриманій, темній редакційній дизайн-естетиці.

## 🚀 Технологічний стек
- **Фреймворк**: Next.js 14 (App Router, Static HTML Export)
- **Мова**: TypeScript (Strict Mode)
- **Стилізація**: Tailwind CSS (користувацькі CSS-токени `#090A0A`, `#D90072`)
- **Оптимізація зображень**: `next/image`
- **Інтернаціоналізація**: i18n (Українська, Польська, Англійська)
- **Доступність**: WCAG AA, клавіатурна навігація, ARIA-атрибути
- **Деплой**: GitHub Actions + GitHub Pages (`output: 'export'`)

---

## 🛠 Інструкція із запуску

### 1. Установка залежностей
```bash
npm install
```

### 2. Запуск у режимі розробки
```bash
npm run dev
```
Сайт буде доступний за адресою: `http://localhost:3000`

### 3. Перевірка типів та лінтера
```bash
npm run typecheck
npm run lint
```

### 4. Продакшн-збірка та експорт
```bash
npm run build
```

## ⚙️ Дані для заміни власником клубу перед запуском

Перед релізом у продакшн оновіть наступні структуровані файли конфігурації:

1. **`src/config/club.config.ts`**:
   - `addressPlaceholder` — адреса клубу (наприклад: `м. Березань, Київська обл.`)
   - `addressMapsUrl` — офіційна посилання-мітка Google Maps
   - `phone` / `email` — контакти адміністрації
   - `socials` — лінки на Instagram, Telegram, TikTok, Facebook
   - `ticketServiceUrl` — посилання на квиткового оператора

2. **`src/content/events.data.ts`**:
   - Афіша та розклад майбутніх подій, ціни на квитки, лайн-ап артистів.

3. **`src/content/campaign.data.ts` & `src/content/gallery.data.ts`**:
   - Офіційні промо-фотографії та галерея закладу.
